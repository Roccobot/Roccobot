# Rocco Casadei · Roccobot

Italian account manager and digital experience specialist by trade. Photographer, graphic designer, video editor, sound engineer, editor, copywriter and marketing specialist, with twenty years of work behind each. Degree in computer engineering, diploma in film direction and screenwriting.

## How I build

I design software the way I design everything else: from the idea to the last pixel. The code is written by AI agents working under my direction. I write the specifications and the rules they follow, make every product and interface decision, review the work and test each release on my own devices before it ships. Every commit names the agent that wrote it.
